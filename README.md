# Jumia E-commerce Clone

## 📌 Overview
This project is a frontend clone of the Jumia e-commerce website. It replicates the structure and layout of a modern online marketplace.

## 🚀 Features
- Responsive design
- Product grid layout
- Navigation bar
- Banner section
- Category display
- Interactive UI elements

## 🛠️ Built With
- HTML
- CSS
